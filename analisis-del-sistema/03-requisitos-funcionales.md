# Requisitos funcionales

| ID | Requisito funcional | HU relacionada |
|---|---|---|
| RF01 | El sistema debe permitir buscar productos mediante criterios de búsqueda. | HU01 |
| RF02 | El sistema debe permitir consultar la información y disponibilidad de los productos. | HU01 |
| RF03 | El sistema debe permitir registrar y actualizar productos en la plataforma. | HU02 |
| RF04 | El sistema debe permitir agregar, modificar y eliminar productos del carrito de compra. | HU03 |
| RF05 | El sistema debe permitir generar un pedido a partir de los productos del carrito. | HU04 |
| RF06 | El sistema debe permitir consultar los pedidos realizados y su estado. | HU06 |
| RF07 | El sistema debe permitir registrar, actualizar y desactivar sellers de la plataforma. | HU05 |
| RF08 | El sistema debe permitir consultar el detalle de un pedido realizado. | HU04, HU06 |
