# Actores del sistema

| ID | Actor | Tipo | ¿Qué necesita realizar? |
|---|---|---|---|
| A01 | Cliente | Usuario | Buscar productos, consultar información, agregar productos al carrito, realizar pedidos, efectuar pagos y consultar pedidos. |
| A02 | Seller | Usuario | Registrar, actualizar y gestionar productos y consultar información relacionada con sus ventas. |
| A03 | Administrador | Usuario | Administrar la plataforma y gestionar los sellers. |
| A04 | Pasarela de pago | Sistema externo | Procesar los pagos realizados por los clientes. |
| A05 | Servicio de envío | Sistema externo | Gestionar la información relacionada con la entrega de pedidos. |
| A06 | Servicio de facturación | Sistema externo | Generar comprobantes de pago. |
| A07 | ERP | Sistema externo | Proporcionar información de productos y stock. |
